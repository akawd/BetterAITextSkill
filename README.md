# Better AI Text

Skill с правилами ясного и естественного русского текста. Предназначен для создания и редактирования текстов, презентаций и сводок.

## Правила

1. [Формулируй мысль прямо, без искусственного противопоставления](references/russian-text-rules.md).
2. [Подкрепляй усиление конкретным содержанием](references/rule-02-unsupported-emphasis.md).
3. [Не создавай показную глубину через подмену вопроса](references/rule-03-false-depth-through-antithesis.md).
4. [Не достраивай перечисления до трёх ради ритма](references/rule-04-decorative-triples.md).
5. [Объясняй значение вместо декларации важности](references/rule-05-explain-significance.md).

У каждого правила есть границы применения и примеры. Конструкции оцениваются в контексте: допустимое противопоставление или содержательное перечисление не нужно удалять автоматически.

## Установка в Codex

Скачайте репозиторий и поместите его содержимое в папку `better-ai-text` в каталоге навыков:

- Для одного проекта: `<проект>/.agents/skills/better-ai-text/`.
- Для пользователя: `~/.agents/skills/better-ai-text/`.

Файл `SKILL.md` должен лежать непосредственно внутри `better-ai-text`, рядом с папками `agents` и `references`. Если навык не появился, перезапустите Codex.

## Использование

```text
Используй $better-ai-text. Отредактируй следующий текст, сохранив смысл и факты:
[текст]
```

```text
Используй $better-ai-text. Подготовь сводку на русском языке по этим материалам:
[материалы]
```

Skill применяется к языку материала. Оформление слайдов и создание файлов презентаций требуют соответствующих инструментов.

## Структура

```text
SKILL.md       — инструкции и ссылки на все правила
agents/        — метаданные для интерфейса Codex
references/    — правила и примеры
```

## Статус

Первая рабочая версия: пять правил. Систематическое сравнение эффективности ещё не проведено.

## Авторство и источники

Правила на основе разбора языковых шаблонов в видео Дмитрия Шарова [«ИИ-текст видно сразу. Признаки, которые выдают ИИ и как их убрать»](https://www.youtube.com/watch?v=sDvBKCPQ56U).
